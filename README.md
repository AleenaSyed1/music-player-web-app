# Music Player Web Application 🎵

A responsive web-based music player developed using HTML5, CSS3, and JavaScript as **Task 3 of my October Web Development Internship at Arch Technologies**.

## Overview

This project provides a simple and interactive music player with playlist management, music search, category filtering, and playback controls. The demo songs are generated directly in the browser, so external audio files are not required to try the demo playlist.

## Features

- 🎵 Playlist displaying song titles, artists, and categories
- 🔍 Search songs by title or artist
- 🎧 Filter music by Chill, Energetic, Focus, and My Files
- ▶️ Play and pause controls
- ⏭️ Next and previous song navigation
- 🔊 Adjustable volume control
- ⏱️ Seek bar with elapsed and total playback time
- 🔀 Shuffle mode
- 📂 Add and play local audio files
- 📱 Responsive layout and dark-mode styling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
- Web Audio API

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Explore the playlist, search, categories, and playback controls.

No additional packages or backend server are required for the browser-based demo.
